# Kitchen Design Canvas Plugin

A lightweight WordPress plugin that adds a frontend kitchen design tool via shortcode.

## Features

- Drag predefined kitchen items into a design canvas.
- Reposition dropped items freely within the room.
- Adjust room width and height.
- Change room color.

## Usage

1. Copy this plugin folder into `wp-content/plugins/`.
2. Activate **Kitchen Design Canvas** from WordPress admin.
3. Add this shortcode to any page or post:

```text
[kitchen_design_canvas]
```
